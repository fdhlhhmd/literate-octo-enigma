Guide

Publishing to GitHub Pages

  1. Images are kept in the storage/ folder of this repository.
  2. metadata.csv is the database. It records each image's filename, title, album, cover flag, tags and tag colours.
  3. To add images, use Upload, then open Database to download the updated metadata.csv and the new images. Put the images in storage/.
  4. Commit and push your changes:
    git add . git commit -m "Add new photographs" git push
  5. Turn on Pages under Settings → Pages. Choose the main branch and the / (root) folder.
